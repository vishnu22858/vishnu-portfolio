## Run Locally

Want to explore or modify the portfolio locally?

**1. Clone the repository**

```bash
git clone https://github.com/vishnu22858/portfolio.git
```

**2. Navigate to the project directory**

```bash
cd portfolio
```

**3. Start a local server**

```bash
python -m http.server 8000
```

**4. Open your browser**

Visit:

```text
http://localhost:8000
```

Alternatively, you can open `index.html` directly in your browser.

## Deployment

This portfolio is hosted for free using **GitHub Pages**.

To deploy your own changes:

1. Push your updated files to the `main` branch.
2. Open your GitHub repository.
3. Navigate to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)` as the deployment source.
6. Save and wait for GitHub Pages to publish the changes.
